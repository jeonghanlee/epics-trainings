# 3.3 Test IOC communication with the simulator

Verify the complete command and reply path:
CA client, stringout record, StreamDevice, asyn TCP, simulator, and readback.

Use three terminals. Complete [Configure the IOC](03.01.yoursecondioc.md)
and [Run the simulator](03.02.iocsimulator.md) first.

## Start the simulator and IOC

1. In terminal 1, start the simulator from `simulator/`:

   ```bash
   ./tcpserver.bash 9399
   ```

2. In terminal 2, activate the matching 1.5.0 environment.
   From `jeonglee_Demo/`, start the IOC:

   ```bash
   cd iocBoot/iocB46_182-jeonglee_Demo
   ./st.cmd
   ```

   Wait for `iocRun: All initialization complete`.
   Enter `dbl` at the IOC prompt. It must list:

   ```
   jeonglee:myoffice:Cmd
   jeonglee:myoffice:Cmd-RB
   ```

3. In terminal 3, activate the same environment and select local searches:

   ```bash
   export EPICS_CA_AUTO_ADDR_LIST=NO EPICS_CA_ADDR_LIST=127.0.0.1
   export EPICS_PVA_AUTO_ADDR_LIST=NO EPICS_PVA_ADDR_LIST=127.0.0.1
   ```

## Send commands and read replies

1. Send an identification query:

   ```bash
   caput -c jeonglee:myoffice:Cmd "DEVICE_ID?"
   caget jeonglee:myoffice:Cmd-RB
   ```

   `caput -c` waits for record processing to complete.
   The readback must contain `DEVICE_ID?`.

2. Send another query:

   ```bash
   caput -c jeonglee:myoffice:Cmd "STATUS?"
   caget jeonglee:myoffice:Cmd-RB
   pvxget jeonglee:myoffice:Cmd-RB
   ```

   Both reads must contain `STATUS?`.

## Observe a lost connection

1. Stop the simulator with Ctrl+C. Send another command from terminal 3:

   ```bash
   caput -c jeonglee:myoffice:Cmd "AFTER_STOP"
   caget jeonglee:myoffice:Cmd.STAT jeonglee:myoffice:Cmd.SEVR
   caget jeonglee:myoffice:Cmd-RB
   ```

   Check the command record's alarm and the IOC log.
   The old readback can remain visible; it is not proof of a successful
   transaction after the simulator stopped.

2. Restart the simulator in terminal 1 and retry the command:

   ```bash
   ./tcpserver.bash 9399
   ```

   ```bash
   caput -c jeonglee:myoffice:Cmd "RECOVERED"
   caget jeonglee:myoffice:Cmd-RB
   ```

   Reconnection is asynchronous. Allow up to 30 seconds, then resend if
   the readback remains unchanged. It must become `RECOVERED`; the command
   record must clear its `INVALID` alarm.

## Verification

Confirm that each successful readback equals the command just sent.
To test an incorrect endpoint, change the startup's TCP port to an unused
port, restart the IOC, and observe the failed transaction. Restore 9399,
restart, and verify another round trip.

Enter `exit` in the IOC terminal and stop the simulator with Ctrl+C.
