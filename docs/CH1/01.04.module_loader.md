# 1.4 IOC startup choices

An input/output controller (IOC) needs executable code, record definitions,
and configuration. This training shows three ways to provide them.

| Method | Use it to learn | Lesson |
| --- | --- | --- |
| `softIocPVX -d water.db` | Load a database with standard record support | [First running IOC](01.02.testenv.md) |
| A compiled application and `st.cmd` | Build an IOC and select support in Makefiles | [First application](../CH2/02.01.yourfirstioc.md) |
| `iocsh.bash st.cmd` | Select installed module support at startup | [Module loader](../CH6/06.01.first_loader.md) |

Chapter 2 starts the application build lessons. Chapter 6 uses the installed
loader and reuses the device files developed in those lessons.
