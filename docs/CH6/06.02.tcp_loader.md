# 6.2 Connect the TCP simulator

Use the Chapter 3 database and protocol with the installed module loader.
You will send a command through StreamDevice and read the simulator's reply.

## Prerequisites

* The [echo simulator](../CH3/03.02.iocsimulator.md).
* The `training.db` and `training.proto` files from
  [Configure the second IOC](../CH3/03.01.yoursecondioc.md).
* The matching 1.5.0 environment activated in every terminal.

## Prepare the loader startup

1. From your `jeonglee_Demo/` application directory, copy the device files
   into a separate workspace:

   ```bash
   mkdir loader_tcp
   cp jeonglee_DemoApp/Db/training.db loader_tcp/
   cp jeonglee_DemoApp/Db/training.proto loader_tcp/
   cd loader_tcp
   ```

2. In `loader_tcp/`, save this file as `st.cmd`:

   ```text
   on error break
   module StreamDevice

   epicsEnvSet("STREAM_PROTOCOL_PATH", ".")
   drvAsynIPPortConfigure("TCP", "127.0.0.1:9399", 0, 0, 0)
   asynOctetSetInputEos("TCP", 0, "\n")
   asynOctetSetOutputEos("TCP", 0, "\n")
   dbLoadRecords("training.db", "P=LOADER:,R=SIM:,PORT=TCP")
   iocInit()
   ```

   `StreamDevice` loads its recorded dependencies, including asyn and calc.
   The loader provides DBD loading and registration. This startup supplies
   the connection, records, and one `iocInit()` call.

3. In `loader_tcp/`, inspect the selected module paths:

   ```bash
   iocsh.bash -n st.cmd
   ```

## Run the device connection

1. In the simulator terminal, start the Chapter 3 echo server:

   ```bash
   ./tcpserver.bash 9399
   ```

2. In `loader_tcp/`, start the IOC:

   ```bash
   iocsh.bash st.cmd
   ```

3. In an activated client terminal, direct searches to this host:

   ```bash
   export EPICS_CA_AUTO_ADDR_LIST=NO EPICS_CA_ADDR_LIST=127.0.0.1
   export EPICS_PVA_AUTO_ADDR_LIST=NO EPICS_PVA_ADDR_LIST=127.0.0.1
   ```

4. Send and read a command:

   ```bash
   caput -c LOADER:SIM:Cmd "DEVICE_ID?"
   caget LOADER:SIM:Cmd-RB
   pvxget LOADER:SIM:Cmd-RB
   ```

   Both reads must contain `DEVICE_ID?`. Repeat with another message:

   ```bash
   caput -c LOADER:SIM:Cmd "STATUS?"
   caget LOADER:SIM:Cmd-RB
   ```

## Verification

The reply must match the message you sent. Inspect `LOADER:SIM:Cmd.STAT`
and `LOADER:SIM:Cmd.SEVR` if the reply stops changing:

```bash
caget LOADER:SIM:Cmd.STAT LOADER:SIM:Cmd.SEVR
```

Stop and restart the simulator, allow up to 30 seconds for reconnection,
then send another message to confirm recovery.
Enter `exit` in the IOC terminal and stop the simulator when finished.
