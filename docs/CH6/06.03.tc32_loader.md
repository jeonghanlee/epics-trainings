# 6.3 Read 32 temperature channels

Run the Chapter 4 temperature database with installed StreamDevice support.
The loader uses the generated database; it does not need the compiled
`jeonglee_Demo` executable.

## Prerequisites

* The [TC-32 emulator](../CH4/04.04.iocsimulator3.md).
* The generated `db/TC-32.db` and `db/tc32.proto` from
  [Database templates](../CH4/04.05.db_templates.md).
* The original template and substitutions restored after the Chapter 4.5
  exercises, so the generated record names retain `$(P)$(R)` macros.
* The matching 1.5.0 environment activated in the IOC and client terminals.

## Prepare the startup

1. From the `jeonglee_Demo/` application directory, create a workspace:

   ```bash
   mkdir loader_tc32
   cp db/TC-32.db db/tc32.proto loader_tc32/
   cd loader_tc32
   ```

2. In `loader_tc32/`, save this file as `st.cmd`:

   ```text
   on error break
   module StreamDevice

   epicsEnvSet("STREAM_PROTOCOL_PATH", ".")
   drvAsynIPPortConfigure("TC32", "127.0.0.1:9399", 0, 0, 0)
   asynOctetSetInputEos("TC32", 0, "\n")
   asynOctetSetOutputEos("TC32", 0, "\n")
   dbLoadRecords("TC-32.db", "P=LOADER:,R=TC32:,PORT=TC32")
   iocInit()
   ```

3. Preview the startup:

   ```bash
   iocsh.bash -n st.cmd
   ```

## Read the live temperatures

1. In the emulator's directory, start one device:

   ```bash
   ./tc32_emulator.bash --port 9399
   ```

2. In `loader_tc32/`, start the IOC:

   ```bash
   iocsh.bash st.cmd
   ```

3. In an activated client terminal, select local searches:

   ```bash
   export EPICS_CA_AUTO_ADDR_LIST=NO EPICS_CA_ADDR_LIST=127.0.0.1
   export EPICS_PVA_AUTO_ADDR_LIST=NO EPICS_PVA_ADDR_LIST=127.0.0.1
   ```

4. Read representative channels and their metadata:

   ```bash
   caget LOADER:TC32:CH01 LOADER:TC32:CH16 LOADER:TC32:CH32
   caget LOADER:TC32:CH01.EGU LOADER:TC32:CH01.DESC LOADER:TC32:CH01.SEVR
   pvxget LOADER:TC32:CH01
   ```

   Temperatures must be between 10 and 90. The units are `Celsius`.
   Wait for live updates before judging a channel's startup value.

## Verification

Read every channel once:

```bash
for ch in {01..32}; do caget -t "LOADER:TC32:CH$ch"; done
```

All 32 values must be between 10 and 90. Monitor three channels:

```bash
camonitor LOADER:TC32:CH01 LOADER:TC32:CH16 LOADER:TC32:CH32
```

Each must receive updates. In the IOC terminal, enter `dbl` and confirm
the names `LOADER:TC32:CH01` through `LOADER:TC32:CH32`.
A published PV alone does not prove that it is receiving device data.

Stop the monitor with Ctrl+C. Enter `exit` in the IOC terminal, then stop
the emulator with Ctrl+C.
